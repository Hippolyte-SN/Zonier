2 Préparation des données

nomcol_y <- "Mtt_total" 
modele <- Mtt_total ~ sexe + Age + qualite + codeGarantie + Exposition

data_mdl <- Base_sim
data_mdl$Mtt_total[data_mdl$Mtt_total <= 0] <- 1

set.seed(123)

index_train <- createDataPartition(data_mdl$Mtt_total, p = 0.75, list = FALSE)

train <- data_mdl[index_train, ]
test  <- data_mdl[-index_train, ]

Definition de la validation croisee

ctrl <- trainControl(
  method = "cv",
  number = 5,
  verboseIter = TRUE

2.3 Comparaison des modèles

Interprétation de la figure

On compare les performances des modèles de régression : CART, GLM, RF (Random Forest) et GBM (Gradient Boosting Machine) selon trois métriques : MAE, RMSE et R².

MAE (Mean Absolute Error)

  • Le MAE mesure l’erreur moyenne absolue entre les prédictions et les valeurs réelles.
  • Plus le MAE est petit, meilleur est le modèle.

RMSE (Root Mean Squared Error)

  • Le RMSE mesure l’erreur quadratique moyenne, donc pénalise davantage les grosses erreurs.
  • Plus le RMSE est faible, meilleur est le modèle.

R² (Coefficient de détermination)

  • Le R² mesure la proportion de variance expliquée par le modèle.
  • Plus le R² est élevé (proche de 1), meilleur est le modèle.
